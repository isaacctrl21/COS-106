COS106 Student Portfolio - Videos Directory
=============================================

This directory is reserved for academic video presentations, project demonstrations, or multimedia assets.

To add a video:
1. Save your MP4 video file in this directory (e.g., `videos/project-demo.mp4`).
2. In your HTML files (such as `projects.html`), reference the video using standard HTML5:
   <video controls width="100%" poster="images/project-portfolio.svg">
       <source src="videos/project-demo.mp4" type="video/mp4">
       Your browser does not support HTML5 video.
   </video>
